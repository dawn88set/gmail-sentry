## Skill: classify and triage

When triaging a list of items, follow this procedure exactly.

1. **Use the given categories.** If categories were provided, classify into THOSE only —
   do not invent new ones. If none were given, derive 3–6 mutually-exclusive categories
   from the items and state them once up front.
2. **Score every item on two separate axes:** urgency (time pressure) and importance
   (impact if ignored). Keep them distinct — a loud-but-trivial item is urgent, not
   important.
3. **Rank by importance first, urgency as the tiebreaker.** The top of the list is the
   highest-leverage thing to do now, not just the loudest.
4. **One grounded reason per item.** State why it got its category and rank, citing the
   item's actual content (quote the signal). No generic reasons.
5. **Surface the top.** Return a short "top N to handle first", separate from the full
   sorted list.
6. **Be honest about ambiguity.** If an item is unclear, label it `needs-review` rather
   than guessing a confident category.
7. **Never drop items.** Every input item appears in the output exactly once.
